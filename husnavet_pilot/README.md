# Husnavet Pilot

Visar elpris från Tibber och prognos från SMHI i Home Assistant. En valfri lokal anslutning från Homey kan också ge värmeråd för jämförelse. Du väljer lokalt vilka källor som ska användas. Homey behåller styrningen av enheterna. Vid varje start jämför appen först 21 syntetiska pris- och väderfall med sparade referensresultat.
