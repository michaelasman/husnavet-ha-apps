# Husnavet VV stop receiver

Separat stoppmottagare för Husnavet VV på Home Assistant Green. Installationen hämtar version 0.1.0 från en privat avbildning i GitHub Container Registry. Använd den registrerade GHCR-inloggningen om den har läsbehörighet till paketet.

Lämna appen stoppad och portmappningen tom vid installation. Mottagaren har separat lokal konfiguration och journal. Den tas i drift först efter verifiering av autentisering, den bundna utrustningen och hela stoppvägen.
